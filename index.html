出行提醒

🗓️10月1日行程紧凑，新街口到禄口机场地铁约80分钟，注意航班时间
⚡10月5日三星堆+都江堰行程最满，建议7:30起床，带好充电宝和干粮
✈️10月7日18:30航班，建议15:00从W酒店出发去双流机场
👟重庆地形多坡道楼梯，务必穿舒适运动鞋
🌃洪崖洞夜景人多，建议提前占位，上千厮门大桥拍全景
🎫成都博物馆已预约10月6日13:00~18:00，记得准时
🌡️重庆湿热注意防暑；成都早晚温差大，带件薄外套
🍲火锅量力而行，备好肠胃药。国庆人多，建议早起错峰

每日行程

基于地理位置规划的科学线路，减少来回奔波 · 天气为10月当地预计

重庆 · 南岸区到渝中区

康莱德 → 弹子石 → 下浩里 → 龙门浩 → 解放碑 → 十八梯 → 山城步道 → 洪崖洞
💡 上午南岸区步行游览（弹子石、下浩里、龙门浩相邻）；下午过江逛解放碑、十八梯、山城步道；晚上看洪崖洞夜景，上千厮门大桥拍全景

重庆 · 渝中区深度游

来福士 → 鹅岭二厂 → 李子坝 → 三峡博物馆 → 湖广会馆 → 朝天门
💡 上午鹅岭二厂拍照，李子坝看轻轨穿楼；下午三峡博物馆（需预约）；傍晚湖广会馆；晚上朝天门夜景

重庆 · 渝北区到转场

来福士 → 光环购物公园 → 重庆北站
💡 上午退房后去光环购物公园（室内植物园），顺路去重庆北站，方向一致不绕路

成都 · 广汉与都江堰一日游

希尔顿 → 三星堆 → 都江堰 → 都江堰站 → 犀浦站 → 希尔顿
💡 这天行程很满！7:30起床，9:10出发去成都东站。三星堆约3小时，下午打车去都江堰约1小时。晚上20:27坐高铁S5058回犀浦，再打车回酒店。带好充电宝和干粮！

成都 · 文化游与返程

W酒店 → 杜甫草堂 → 成都博物馆 → 东郊记忆 → 武侯祠/锦里 → 双流机场
💡 10月6日：上午杜甫草堂，下午成都博物馆，晚上东郊记忆。10月7日上午武侯祠+锦里或宽窄巷子或人民公园喝茶，15:00出发去机场
