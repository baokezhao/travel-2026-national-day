# 2026 国庆旅行 · 重庆成都

我和妞妞的七天旅行计划网页（2026.10.1 — 10.7），包含行程总览、每日行程、旅行账本、旅行地图、Vlog 素材、智能行程调整。

## 在线访问

https://baokezhao.github.io/travel-2026-national-day/

## 文件结构

| 文件 | 职责 |
|------|------|
| `index.html` | 页面结构（纯 HTML，引用外部样式和脚本） |
| `style.css` | 样式（莫兰迪配色、CSS 变量系统化） |
| `data.js` | 数据（8 天行程、30 笔费用、景点词典、提醒文案） |
| `app.js` | 逻辑（渲染、交互、账本、智能调整、初始化） |

## 本地预览

```bash
cd travel-2026-national-day
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000/
```

## 更新方法

- 改**样式** → 编辑 `style.css`
- 改**行程/费用/景点数据** → 编辑 `data.js`
- 改**逻辑/交互** → 编辑 `app.js`
- 改**页面结构** → 编辑 `index.html`

改完后提交并推送：

```bash
git add -A
git commit -m "更新说明"
git push
```

推送后 GitHub Pages 会自动重新构建，约 1-2 分钟后线上链接更新。

## 功能说明

- **总览**：行程时间轴、费用占比环形图、分类金额条形图、可展开的出行信息卡片
- **行程**：基于地理位置的线路规划、每日详细日程（含天气）
- **账本**：记录每一笔花费，按类别筛选，金额实时汇总
- **地图**：按天分组的景点流程图（重庆/转场/成都）
- **Vlog**：每日拍摄重点建议
- **调整**：输入自然语言调整行程，所有页面同步更新

## 数据存储

账本、备注、行程调整均保存在浏览器 localStorage 中（每台设备独立存储），不上传服务器。
